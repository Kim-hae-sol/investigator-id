# 플레이트 제작 기록

2026-11-02, 내장 `image_gen` 사용. 기존 프로젝트의 실제 WebGL 캡처를 편집 대상으로 사용하고
동일한 방의 생성 결과를 재질·조명 참조로 사용했다. 외부 스톡 사진이나 새 3D 모델을 다운로드하지 않았다.
합성 이미지이며 촬영 실사, 실제 장소, 실제 허남준의 사진으로 표기하지 않는다.
이 생성물에 임의의 CC0 같은 외부 라이선스를 붙이지 않는다. 기존 라이브러리/PBR/음원 출처 문서는 유지한다.

최종 프롬프트 세트의 요구:

- **복도 wide**: 기존 1인칭 캡처의 모든 문·손잡이·슬롯·조명·소실점·카메라를 유지. 실제 촬영한 고급
  누아르 세트처럼 물성을 교체. 월넛 베니어, 브론즈, 매트 석재, 차콜 플라스터, 따뜻한 실제 광원.
  녹색 공포물·안개·블룸·강한 비네팅·플라스틱·CG·UI·인물 금지.
- **문 앞**: 기존 정면 도착 캡처를 정확히 보존하고 wide와 동일한 재질·조명. 별도 정밀 편집으로
  벽의 금속 카드 리더만 제거하고 플라스터 복원. 실제 3D 리더가 배경과 중복되지 않도록 clean plate 사용.
- **room seated**: 기존 착석 구도·가구 경계·보드·종이·컵·트레이를 유지. 같은 건물의 실제 촬영 질감.
  맞은편 기존 의자에 여유롭게 약간 비스듬히 앉은 완전히 옷을 입은 성인 익명 남성 대역 한 명.
  얼굴·눈·신원은 자연스러운 그림자로 식별 불가. 보스/왕좌/공포 자세 금지. 새 얼굴 정체성 요구 없음.
- **room clean**: 위 생성본에서 남성과 손만 제거하고 빈 의자와 책상 복원. 나머지 카메라·소품·조명 유지.
- **room desk**: 기존 내려다보기 캡처의 테이블·컵·파일·패드·트레이·책 위치 유지. seated와 같은 월넛,
  가죽·종이·빛. 화면 위쪽에 자연스럽게 잘린 동일 익명 대역의 몸통·팔, 얼굴은 프레임 밖.
  중앙 크라프트 파일의 작은 미색 라벨은 빈칸. UI·텍스트 금지.
- **room entry**: 기존 문턱 캡처의 모든 경계·카메라·가구 위치를 유지하고 clean과 같은 재질로 교체.
  창문 없는 따뜻한 실내광. 의자는 비워 둠. 인물은 별도 레이어로 합성. 새 소품이나 텍스트 금지.

모든 프롬프트 공통: 전체 16:9, 사진 같은 자연스러운 표면과 노출, 변형된 건축/과장된 광원/안개/블룸/
오렌지 일색/공포/게임 렌더 금지. 실제 배우 자료를 흉내 낸 얼굴은 생성하지 않음.

인물은 임시 대역이며 향후 권한이 확보된 실사 인물 레이어로 교체해야 한다. 이 폴더와
`cinematic-plates.js`의 보정 카메라·윤곽을 함께 관리한다.
