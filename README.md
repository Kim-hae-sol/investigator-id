# HNJ — 조사관 ID 발급 · 3D 복도

카드 한 장을 작성·발급받고 실제 3D 복도를 걸어 닫힌 조사실 문 앞에 도착하는 장면입니다.
프레임워크, 빌드, 외부 폰트나 실행 중 외부 에셋 다운로드가 필요하지 않습니다.

## 실행

`dist/index.html`을 브라우저에서 열면 바로 실행됩니다.
또는 프로젝트 폴더에서 `python3 -m http.server 4178 --directory dist`를 실행한 다음
`http://localhost:4178`에 접속합니다.

## 구조

- `dist/index.html` — 장면, 카드, 접근성 레이블
- `dist/styles.css` — 카드 재질, 금속 클립, 조명, 도장 모션, 작은 화면 대응
- `dist/app.js` — 이름 입력, 사진 처리, 효과음, 자동 코드네임, 발급 상태, 브라우저 보관, 다음 장면 연동
- `dist/opening.js` — 같은 페이지 전환, 연속 복도 이동, 다섯 걸음, 문 앞 정지
- `dist/opening.css` — 새 장면에만 적용되는 화면·이미지·WebGL 스타일
- `dist/corridor-3d.js` — 미터 단위 복도, 문/문틀/금속 손잡이, PBR 재질, 조명/그림자/반사, 실제 카메라 이동
- `dist/vendor/` — 로컬 Three.js r180, 공식 Reflector, MIT 라이선스
- `dist/assets/pbr/` — 월넛·플라스터·테라조 재질과 CC0 출처 문서
- `dist/assets/corridor-start.png` — WebGL을 지원하지 않는 환경의 복도 대체 이미지
- `dist/assets/door-arrival.png` — 향후 촬영/비주얼 참고용 근접 이미지
- `dist/assets/shoe-steps.wav` — 실제 구두 발걸음 녹음에서 다듬은 네 개의 발소리
- `dist/assets/AUDIO.md` — 구두 녹음의 출처, CC0 라이선스, 편집 내역
- `dist/assets/ASSETS.md` — 에셋 구분, 교체 방법, 내장 ImageGen 최종 프롬프트
- `package.py` — 이미지까지 내장한 단일 HTML과 소스 ZIP 재생성
- `.openai/hosting.json` — Sites 배포 설정

이름 또는 닉네임만 직접 입력합니다. 사진은 기존과 같이 선택이며, 없으면 실루엣으로 발급됩니다.
발급 전에는 CODE NAME이 `—`, STATUS가 `PENDING`입니다.
발급 버튼을 누르면 `AGENT H-001`~`AGENT H-999` 중 하나를 무작위로 부여하고,
STATUS를 `AUTHORIZED`로 변경한 뒤 기존 스탬프 모션과 효과음을 실행합니다.
식별번호는 방문자 간 중복될 수 있습니다. 발급 중에는 이름·사진·발급 버튼이 잠깁니다.
발급 후 카드 아래에는 환영 문구, `조사실 입장 →`, `↺ 다시 작성` 순서로 표시됩니다.
조사실 입장을 누르면 새 탭이나 경로 이동 없이 같은 페이지에서 복도 오프닝이 시작됩니다.
사진은 처음에는 기존 구도로 표시되며, 발급 전에 사진 위에서 드래그해 위치를 옮길 수 있습니다.
사진 안의 작은 슬라이더 또는 `− / +` 버튼으로 축소·확대합니다. 사진 전체가 보이도록
줄이거나 기존 크롭의 3배까지 확대할 수 있습니다. 마우스 휠도 확대·축소를 지원합니다.
터치 드래그를 지원하며, 사진에 키보드 초점을 두고 방향키로 이동하거나 `+ / -`로 크기를
바꿀 수도 있습니다. `Home`은 기본 구도로 돌아갑니다. 사진 변경 버튼은 우측 하단에 유지됩니다.
흑백 톤과 카드의 사진 영역 크기는 기존과 같습니다.
JPG / PNG / WEBP / AVIF / GIF, 최대 15MB를 지원합니다.
`다시 작성`은 저장된 발급 정보를 초기화하고, 현재 이름·사진을 유지한 채 편집을 다시 엽니다.
이때 코드네임은 `—`, STATUS는 `PENDING`으로 돌아갑니다. 다음 발급 때 새 번호를 추첨합니다.
무작위이므로 재발급 결과가 이전 번호와 같을 수도 있습니다.

완성된 카드의 이름·코드네임·발급 시각·사진과 조정한 구도는 IndexedDB에 저장하여 같은 브라우저에서
새로고침해도 복원합니다. 사진은 Blob으로 보관하며 외부 서버로 전송하지 않습니다.
재발급 준비 또는 브라우저의 사이트 데이터 삭제 시 보관된 카드가 초기화됩니다.
저장소가 차단되거나 저장 한도를 초과하면 현재 페이지에서만 발급 상태를 유지합니다.
효과음 설정은 기존과 같이 localStorage에 보관합니다.
타자기·스탬프 효과음은 기존 Web Audio 합성을 유지합니다. 복도 발소리는 실제 구두 녹음을
내장하여 재생합니다. 모든 효과음은 사용자 조작 후 시작하며 하단에서 켜고 끌 수 있습니다.
동작 줄이기 설정을 사용하면 발급 모션을 즉시 처리합니다.

## 복도 오프닝

입장 클릭 즉시 중복 실행을 잠그고, 약 0.72초 암전 → 0.17초 정적 → 페이드인 없이 복도 등장 →
약 4초 전진 → 닫힌 문 앞 정지 순서로 재생합니다. 이동 중 다섯 번의 실제 여성 하이힐 구두 소리를 재생합니다.
발걸음 간격은 약 0.75초이며, 하이힐 굽의 접촉과 밑창·단단한 바닥의 자연스러운 잔향을 보존했습니다.
저음 보강을 제거하고 140 Hz 아래를 줄여 가볍고 또렷하게 재생합니다.
기존의 짧은 합성 클릭음은 제거했습니다. 프레임 갱신은 requestAnimationFrame으로 부드럽게 유지합니다.
발소리와 미세한 보행 움직임은 같은 requestAnimationFrame 시간축을 사용합니다.
배경 탭에서는 이동을 일시 정지하여 복귀 시 발소리가 한꺼번에 나오지 않도록 합니다.
기존 SOUND ON/OFF 및 사용자 클릭으로 시작한 Web Audio 문맥을 그대로 사용합니다.
OFF일 때 새 발소리를 만들지 않으며 이동 도중 꺼도 해당 출력 채널을 즉시 낮춥니다.
동작 줄이기 설정에서는 걷기와 발소리를 건너뛰고 문 앞 장면으로 짧게 전환합니다.

카드 DOM과 발급 정보는 메모리 및 기존 IndexedDB에 그대로 유지합니다.
새로고침하면 발급된 ID 카드부터 복원됩니다. 문 앞에서 다른 장면으로 자동 이동하지 않습니다.
슬롯, 인증, 손잡이 클릭, 문 열기, 내부, 인물, 파일 열람은 구현하지 않았습니다.

기본 장면은 WebGL2 / Three.js r180으로 구성한 실제 3D 공간입니다. 사진 확대와 디졸브를
사용하지 않습니다. 벽·천장·바닥·문·문틀·손잡이·조명을 각각 모델링하고 카메라를
z = 7.25 m → 3.20 m로 약 4초간 전진시킵니다. 문턱, 몰딩, 판재 모서리에도 실제 두께가 있습니다.
폭 2.48 m, 높이 2.94 m, 전체 깊이 13.8 m 공간에 좌우 문을 2.10 m, 천장 조명을 2.15 m 간격으로 반복합니다.
짧은 가속, 일정한 보행, 부드러운 감속을 통해 4.05 m를 이동합니다.
같은 시간축의 발걸음에 맞춰 눈높이와 좌우 위치에 수 mm의 움직임만 넣습니다.
도착 후에는 RAF 이동을 종료하며 창 크기가 달라질 때에만 다시 그립니다.

월넛 문, 도장한 플라스터, 테라조 타일은 로컬 CC0 PBR 재질입니다. 노멀과 거칠기 맵,
부드러운 그림자, 낮은 강도의 바닥 반사를 적용합니다. 광원과 건물이 고정되어 있으므로
그림자 맵을 매 프레임 다시 만들지 않습니다. 반복 문 부품은 인스턴싱으로 묶습니다.
목재마다 결 위치와 색을 미세하게 다르게 하고, 거칠기의 하한을 적용해 플라스틱 같은 반사를 줄였습니다.
문틀·걸레받이 접점의 약한 음영과 반복 조명의 밝고 어두운 구간으로 깊이를 표현합니다.
정면 문에는 작은 별도 조명을 두고 전체 문과 주변 벽면을 함께 보여 줍니다. 픽셀 비율은 최대 1.6으로 제한합니다.
Three.js와 모든 재질·구두 녹음을 파일에 포함하므로 실행 중 CDN이나 외부 서버를 요청하지 않습니다.
WebGL2를 사용할 수 없으면 기존 사진 장면을 대체 화면으로 사용합니다.

데스크톱은 16:9 장면을 화면 안에 맞춥니다. 1440×900처럼 비율이 다르면 레터박스가 생깁니다.
세로 휴대폰에서는 4:5 창에 맞춰 실제 카메라 종횡비를 다시 계산하며 문 전체를 중앙에 유지합니다.
ID 카드의 styles.css, 카드 HTML, app.js의 발급·사진·보관 기능은 변경하지 않았습니다.

## 3D 장면 수정 및 단일 HTML 만들기

공간 크기, 눈높이, 시작·도착 거리, 시야각은 corridor-3d.js 상단 SPACE에서 조절합니다.
문은 door(), 조명은 lamp(), 재질은 pbr() 호출부에서 수정합니다. 새로운 문 모델을 넣을 때도
mainDoor 그룹을 유지하면 다음 단계의 슬롯·문 인터랙션과 연결할 수 있습니다.
기하와 카메라 변경 없이 표면만 교체하려면 assets/pbr/의 color / normal / roughness JPEG를
같은 이름으로 교체하고 package.py를 실행하세요. 재질별 출처·라이선스는 assets/pbr/CREDITS.md에 있습니다.

기존 생성 이미지는 WebGL 대체 화면 및 룩 참고로 유지했습니다. 실제 장소를 촬영한 사진으로
표기하지 않습니다. 사진 대체 화면의 경로는 #corridor-plate / #door-plate이며 기존 생성
프롬프트와 교체 방법은 assets/ASSETS.md에 남겨 두었습니다.

```sh
python3 package.py --output-dir /원하는/내보내기/폴더
```

이 명령은 `investigator-id.html`에 3D 라이브러리·재질·대체 이미지·스타일·스크립트를 모두 내장하고,
수정 가능한 소스 폴더와 `investigator-id.zip`을 함께 생성합니다. 실행에는 Python이 필요하지 않습니다.
`assets/shoe-steps.wav`도 opening.js에 내장하므로 로컬 파일로 열어도 CORS나 오디오 다운로드 없이
재생합니다. WAV를 교체할 때에는 네 개의 .52초 발걸음을 .60초 간격으로 배치한 2.4초 스프라이트를
유지한 뒤 package.py를 실행하세요. 새 폴더형 opening.js와 단일 HTML에 함께 반영됩니다.

## 다음 장면 연결

```js
window.addEventListener('investigator:issued', ({ detail }) => {
  // 발급 모션 완료 후 발생합니다. 카드 발급 데이터를 받는 용도입니다.
  // detail = { name, codeName, status: 'AUTHORIZED', title, serial, photoUrl, photoFraming, issuedAt }
  console.log(detail.name, detail.codeName);
});

window.addEventListener('investigation:enter', ({ detail }) => {
  // '조사실 입장' 클릭 후 발생하며 opening.js가 복도 이동을 시작합니다.
});

window.addEventListener('investigation:arrived', ({ detail }) => {
  // 닫힌 조사실 문 앞에 완전히 멈춘 뒤 발생합니다.
  // 다음 단계: #door-interaction-layer에 실제 슬롯 / 문 인터랙션을 연결하세요.
});

const identity = window.HNJ.getIdentity(); // 발급 전 null, 발급 후 읽기 전용 객체
// window.HNJ.enterInvestigationRoom(); // 발급 후에만 복도 오프닝을 요청합니다.
```

`photoUrl`은 현 페이지 수명 동안만 유효한 Blob URL입니다. 페이지를 넘길 때에는 별도의
사용자 동의를 포함한 전달 방식을 구현하세요. 현재의 AUTHORIZED 및 승인 도장은 연출이며
실제 인증/출입 권한을 부여하는 백엔드는 포함하지 않습니다.

`photoFraming`은 `{ zoom, x, y }`입니다. zoom은 cover 배율에 대한 상대 크기이며,
x/y는 이미지와 프레임 사이 공간에 대한 0~1의 정규화된 위치입니다.
이전 버전에서 보관한 사진도 기본 구도로 호환하여 복원합니다.
